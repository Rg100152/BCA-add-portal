## 🚀 Features

### 🔐 Authentication System
- User registration with password strength meter
- Secure login with email/mobile
- Password visibility toggle
- "Remember Me" functionality
- Password reset flow (demo-ready)

### 📝 Multi-step Application Form
- **5-step progressive form** with visual progress indicator
- Step 1: Personal Information (name, DOB, address, parents details)
- Step 2: Academic Qualifications (Class X, XII, entrance exams)
- Step 3: Category & Preferences (reservation, specialisation, hostel)
- Step 4: Document Upload (photo, signature, marksheets, certificates)
- Step 5: Review & Submit

### 🎨 UI/UX Highlights
- **Cyberpunk/Neon theme** with animated gradient background
- Responsive design (mobile, tablet, desktop)
- Smooth animations and transitions
- Real-time form validation
- Password strength indicator
- Interactive radio buttons and file upload cards
- Toast notifications for user feedback

### 📊 Data Management
- LocalStorage-based user persistence
- Application ID generation (RGIT format)
- Session management
- Auto-login on revisit
